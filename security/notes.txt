Relational Fields-Vid(22-23-24)-:
note from DB Mapping --->  in one2many or many2one ----> the id from one entity be forign key in the many entity
1-many2one  ===>  many records from one table are related with only one record from other table    (many invoices ---> one client)    ----> new field in first table (many) showing the relation   ==> recorded in database
2-one2many  ===>   only one record from one table is related with many records from other table    (one invoice   ---> many items)    ----> new field in the second table (many) showing the relation  ===> unique foe each entitity can not be common
3-many2many ===>   many records from one table is related with many records from other table      (one invoice    ---> many items)     ----> new table is created  ==> recorded in data base with new table ===> can be common for different records

    Vid(31):decorators ===>
    1- @api.depends(*args) ====> *args = simple fields  + relational fields ===> any change in *args whether from the ui or db ===> the ecorator will call the method
    # computed (derived) field ==> is not stored in DB.
    diff = fields.Float(compute='_compute_diff')

      # can pass all fields in the same model + the realtional field with other models
    # is a real  record, we can  apply crud operation on it
    @api.depends('expected_price', 'selling_price', 'owner_id.phone')
    def _compute_diff(self):
        for rec in self:
            print('inside _compute_diff method')
            rec.diff = rec.expected_price - rec.selling_price



    2- @api.onchange(*args) ===> *args = simple fields only ===> must be views fields that i can change from the ui (form vieww) and tree if it has multiedit attribute
    # can pass all fields in the same model only (views fields)
    # return a pesudo  record, we can not apply crud operation on it we can use dot notation or method called update
    # application ==> warnining ===> it does not prevent me from recording in DB
    @api.onchange('expected_price', 'owner_id.phone')
    def _onchange_expected_price(self):
        for rec in self:
            print('inside _onchange_expected_price method')
            return {
                'warning': {
                    'title': 'warning',
                    'message': 'negative value',
                    'type': 'notification'
                }
            }
